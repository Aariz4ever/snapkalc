# Nutrition Tracker (Next.js PWA)

    npm install
    npm run dev          # http://localhost:3000
    npm run build        # static site in ./out
    npm start            # serve ./out

Deploy `out/` to any static host over HTTPS (Vercel, Netlify, Cloudflare Pages, GitHub Pages at the domain root).
Open it on your phone, then **Add to Home Screen** (iOS Safari: Share → Add to Home Screen; Android Chrome: menu → Install app).
Data lives in the device's localStorage and works offline after the first visit. Use Settings → Export backup to keep a copy.

Single-day tracker: use **Clear day** to reset, **Share** to send the day's summary to a trainer or dietitian.
